# Амадея

Локальный исследовательский агент для Windows x64. Её личность задана одной строкой в [identity.md](identity.md). Остальные параметры эксперимента находятся в [settings.toml](settings.toml).

## Запуск

Откройте `run.cmd` и пишите в консоль обычным языком. Амадея отвечает текстом и голосом. В паузах она сама формулирует вопросы, планирует, читает и иногда начинает разговор. Для завершения нажмите Ctrl+C.

`setup.cmd` подготавливает папку на новом ПК. После подготовки Python, зависимости, веса, рабочее состояние и адаптеры лежат рядом с программой. Для переноса скопируйте папку. Для CUDA нужен совместимый драйвер NVIDIA. Windows должна оставаться запущенной, а для работы с окнами нужен открытый пользовательский сеанс.

## Как устроен эксперимент

- **Память.** События сохраняются в SQLite. Рабочий контекст содержит короткую сводку накопленного опыта, свежие события и несколько результатов поиска по архиву. Сводка обновляется постепенно, исходные события остаются доступны для исследования.
- **Самостоятельные решения.** Модель получает состояние организма, память, открытый вопрос и план. Она выбирает содержание следующего шага и решает, говорить ли вслух. Уровни гормонов изменяются от времени суток, контакта, новизны, награды и нагрузки. Цикл сна и настроение вычисляются из настраиваемой симуляции.
- **Навыки.** Амадея может создавать, перечитывать и улучшать текстовые методики. Каждая редакция сохраняется в SQLite. Среда предоставляет фиксированный набор исполняемых инструментов.
- **Учёба.** В свободные периоды Амадея выбирает новую статью Википедии или ищет конкретную тему. Она извлекает вопросы, ответы и дословные подтверждающие фрагменты. Источники, заметки и учебные примеры сохраняются локально.
- **QLoRA.** Во время сна агент обучает кандидат на новых примерах и части предыдущих. После оценки на отложенных статьях он автоматически активирует прошедший проверку адаптер. Исходные веса и ранее сохранённые адаптеры доступны для воспроизводимости. Метрики каждого завершённого обучения попадают в журнал.
- **Экран.** Можно написать «Посмотри на окно Блокнота и расскажи, что видишь». В Windows откроется диалог выбора доступа. После согласия переключитесь в нужное окно. Пока оно на переднем плане, Амадея может видеть его в этом сеансе. Каждое предложенное перемещение мыши, нажатие или ввод текста показывает отдельный диалог с точным действием.
- **Речь.** Qwen3‑TTS 1.7B CustomVoice использует `Ono_Anna`. Синтез выполняется отдельно от основной модели. Первый ответ вслух может занять больше времени из-за загрузки весов.

### Наставники

Google Gemini задан как браузерный наставник в `settings.toml`. Напишите в консоли «Спроси Gemini через браузер, чем комета отличается от астероида». Амадея откроет страницу в отдельном профиле Chromium. Она получает снимки страницы, выбирает клики, ввод и прокрутку, дожидается ответа и сохраняет прочитанное. Для Gemini достаточно доступа к его веб-интерфейсу. Если страница попросит войти, войдите в открытом браузере и напишите Амадее, что беседу можно продолжить.

При изучении статей Амадея сама обращается к наставнику и может задать уточняющий вопрос. Она сохраняет ответ с адресом страницы. В обучающие примеры из такой беседы попадают факты с дословным подтверждением из статьи. Другие веб-интерфейсы можно добавить в `[[study.teachers]]` с `kind = "browser"`. Записи с `kind = "api"` используют совместимый Chat Completions.

Для обучения управлению браузером генератор создаёт локальные чаты с разными макетами, вопросами и состояниями. LoRA учится выбирать следующее действие по снимку и истории. Отдельные макеты используются для оценки перед активацией. Параметры воспроизводимого обучения находятся в `[browser_training]`.

### Файлы исследования

| Путь | Содержимое |
| --- | --- |
| `state/memory.sqlite3` | Архив событий, сводка, физиология, версии навыков, обучающие примеры и метрики |
| `state/adapters/` | Версии адаптеров LoRA |
| `state/browser-training/` | Учебные снимки, отложенные примеры и результаты проверки |
| `state/browser-profile/` | Отдельный профиль браузерного наставника |
| `state/browser-runs/` | Снимки шагов бесед, связанных с записями в SQLite |
| `state/amadea.log` | Диагностика фонового процесса |
| `models/` | Локальные веса Amadeus и Qwen3‑TTS |
