# Проверка реализации

Проверено 6 ноября 2026 года на Windows x64, RTX 3070 Laptop 8 ГБ.

- Release-сборка C# без предупреждений и ошибок; опубликован self-contained EXE с .NET runtime.
- 37 регрессионных сценариев: атомарная память, загрузка/восстановление, ошибки и конкурентное сжатие, забывание, ограничение эмоций, разрешения, пути, чтение файлов, фильтрация URL, инициативные события без действий, подтверждение запуска, маршрутизация EN/RU, проверка английских ответов и неверного JSON.
- Реальные локальные модели: русский запрос → английский ответ; чтение воспоминания после перезапуска; сжатие памяти моделью; пересказ фактов из настоящего `documents/example.md`; создание и отклонение запроса запуска калькулятора без ложного сообщения о выполнении.
- Vision: модель правильно прочитала слово TEST на искусственном красном изображении.
- Piper → WAV → Whisper: женская английская речь синтезирована и распознана локально.
- Устройства звука и native-системный контекст перечисляются; захват клавиши/запись реализованы, но реальная речь пользователя при разработке не записывалась.
- Windows Job: принудительное завершение тестового родительского процесса немедленно завершило его дочерний процесс.
- `Start.cmd --diagnose`: все пути моделей/движков существуют; запуск через Windows PowerShell 5 проверен.

Реальный GDI-захват экрана из изолированной сессии разработки вернул Win32 error 5 (Access Denied). Это обработано без остановки диалога. Требуется проверить `/look` при обычном интерактивном запуске; доступ к реальному рабочему столу не был подтверждён этой проверкой.

Повторить проверки:

```powershell
.\Build.cmd
.\Start.cmd --diagnose
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Test-Models.ps1
```

Тестовая переписка и экспериментальное настроение перенесены в `data/development-checks/`. На первом обычном запуске создаётся новая память.
